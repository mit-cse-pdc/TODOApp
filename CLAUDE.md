## Project state

This is a Spring Boot 4.1.0 / Java 17 Maven project, currently at the initial scaffold stage generated by Spring Initializr (`in.manipal.mit.ccd.lab4`, artifact `TODOApp`). There are no controllers, services, entities, or persistence layer yet — only the application entry point (`TodoAppApplication`), a default context-load test, and `application.yaml` (sets `spring.application.name` only). Treat this as a from-scratch build: there is no existing architecture to preserve, so establish conventions deliberately as features are added rather than inferring them from prior code.

Dependencies currently in `pom.xml`: `spring-boot-starter-webmvc` (Spring MVC), `spring-boot-devtools` (runtime), and `spring-boot-starter-webmvc-test` (test). No database/persistence starter (e.g. JPA, JDBC) is present yet — add one when persistence is needed.

## Commands

Use the Maven wrapper (`mvnw` / `mvnw.cmd`) rather than a system-installed Maven.

- Build: `./mvnw compile` (bash) or `mvnw.cmd compile` (Windows shell)
- Run all tests: `./mvnw test`
- Run a single test class: `./mvnw test -Dtest=TodoAppApplicationTests`
- Run a single test method: `./mvnw test -Dtest=TodoAppApplicationTests#contextLoads`
- Package: `./mvnw package`
- Run the application: `./mvnw spring-boot:run`

## Architecture

- Base package: `in.manipal.mit.ccd.lab4`
- `TodoAppApplication` is the `@SpringBootApplication` entry point under `src/main/java/in/manipal/mit/ccd/lab4/`.
- Configuration lives in `src/main/resources/application.yaml` (YAML, not `.properties`) — keep using YAML for new config to stay consistent.
- Tests live under `src/test/java/in/manipal/mit/ccd/lab4/`, mirroring the main package structure.
